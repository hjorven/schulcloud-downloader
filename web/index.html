Schul-Cloud Download

Lädt deine Materialien aus der Schul-Cloud gesammelt herunter. Diese Seite hat keinen eigenen Server: Anmeldung und Downloads laufen direkt zwischen deinem Browser und der Schul-Cloud. Dein Passwort wird nirgends gespeichert.

1. Anmelden

Die Schul-Cloud lässt diese Seite nicht zu. Manche Schul-Cloud-Instanzen blockieren Anfragen von fremden Webseiten. Dann hilft die lokale Version, die genauso aussieht, aber auf deinem Rechner läuft:

python -m pip install git+https://github.com/hjorven/schulcloud-downloader.git
sc-dl web
